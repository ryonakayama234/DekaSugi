# ADR-0006 — Causal World Laboratory and independent source custody

id: ADR-0006
status: proposed_not_merged
updated: 2026-11-02
tags: architecture, research, causal-learning, trust-boundary

## Context
REP003 inquiry mechanism NULL, REP004 utility NEGATIVE against fixed Hplus and REP004R 108-path no-switch demonstrate that executable learned concepts, question activation and real improvement are three different phenomena. REP005 G0a source fixture has at most 14 object-role orbits, so 80 structural families are not available in that fixture. Latest PR #147 review also identifies 4 x (8+4+8) = 80 versus undocumented 160 worlds arithmetic.

## Decision
Choose a finite, typed, deterministic, CPU-first synthetic causal world and **separate** (a) generator hidden law/ancestry and source-only certifier, (b) public episode and learner, (c) evaluator private target and independent audit. G0b itself must measure potential opportunities and independent structural families before future Wake/Sleep is allowed. Do not create a huge generic world DSL or UI.

Maintain a full typed law signature AND publicly reachable signature, with distinct certificates for semantic identity, structure/ancestry, worst-case adaptive identification and public action opportunity. H0_all memoryless contradiction proof and finite H0_G/Hplus_G membership are distinct. M3 noise never coerced into deterministic grammar. A certificate only means constructive independence relative to the declared grammar.

Use JSONL append-only evidence, exact source hash and immutable Snapshot hashes. Use typed AST interpreter, no arbitrary Python. Implement source reference oracle independently. Avoid read permissions from learner to generator/evaluator family and truth. Later domain adapters for games/apps/dialogue can reuse Environment observation/action schema but must demonstrate genuine transfer empirically.

## Rejected alternatives
- Scale seeds/object naming to quota: pseudo-independence.
- Hand-assign four balanced classes before full feasibility census: selection bias and possibly impossible class.
- Add a neural network now: cannot distinguish improved training fit from richer representational opportunities.
- Merge stacked research PRs or modify historical tests: threatens negative/null evidence and previously frozen evaluation.
- Let evaluator/generator train policy through shared mutable catalog: information leakage.

## Consequences and review
Main-based docs-only PR; future implementation separately reviewed. Original Issue #148 scientific acceptance remains unfulfilled. Review source, type/graph semantics, independent class proof, prior and budget definitions, data leak boundary, source hashes and arithmetic before freeze. The initially docs-only Draft PR #149 now stages one isolated synthetic-only G0b-A module and tests. Under the exact <=2 Edge guard grammar, direct enumeration of 100,090,027 syntactic normal forms exceeds the 200,000 candidate cap. The eight constructed examples establish correct mechanics but NOT independent scientific families. No production learner, source-custody process boundary or G1–G6 training was implemented.
