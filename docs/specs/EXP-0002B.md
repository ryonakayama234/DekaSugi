# EXP-0002B — Contextual Skill Utility Kernel

id: EXP-0002B
status: proposed; not implemented
updated: 2026-10-24
tags: kernel, skill-selection, policy-learning, abstention, generalization

## 研究対象
EXP-0002で抽出する技能は常時有効化すると探索空間を拡大し得る。各課題の手持ちの入出力例から事前に観測できる特徴を使い、**技能を試すかどうか**を試行データから学習する小さなKernelを構築する。前提は[PR #6](https://github.com/ryonakayama234/DekaSugi/pull/6)、動機は[Issue #7](https://github.com/ryonakayama234/DekaSugi/issues/7)。

## 判断する対象の限定
- 行動 `a ∈ {OFF, ON(skill)}`。初回はmacro一種に限定し、技能候補の生成や新しい原始演算の追加には介入しない。
- 状態 `TaskFeatures` は入力/出力例の長さや文字種などの既知例の性質。探索して得たASTや最終ベンチマーク結果は特徴に入れない。
- 報酬: 正しさと安全性を最優先とする制約付きコスト削減。**評価した候補数と総原始演算呼出数**は別集計。wall timeは参考。
- 学習方式: 少数データで再現可能な近傍型もしくは小さな表形式推定器を比較し、1方式と全設定を学習実装前に事前登録する。事前学習済みLLMは使用しない。
- 選択に十分な観測がなければ `OFF` にフォールバックする。信頼度・判断理由を保存。

## 比較実験: 4条件
| Condition | 内容 | 用途 |
|---|---|---|
| OFF | 原始演算のみ | 正確性・探索コストの基準 |
| ON | すべての課題で技能追加 | EXP-0002型の広範な技能活性化の基準 |
| LEARNED | 訓練済みKernelが課題ごとにON/OFF | 主たる学習条件 |
| ORACLE | 最終結果を見た後に都合の良い方を選ぶ | 非実用的な上限であり、採用条件には使用しない |

## データ契約・分割
契約は[ARCH-002](../architecture/contracts.md)。学習用、モデル選択用、独立保留用のタスクfamily / 乱数seed / 文字列集合を分離。EXP-0002の公開済み保留課題は**新しい最終評価の代わりにはならない**。具体的なdatasetと固定閾値は[実験計画案](../../experiments/EXP-0002B/plan.md)で実装前に登録する。

## 検証ゲート
- EXP-0001/0002の契約・安全・再現性を壊さない。
- 最終評価でLEARNEDがONのみ・OFFのみと比べてどの程度差があるかを計測。正解率、候補数、原始演算数、推論オーバーヘッド、誤選択、分位点を記録。
- 数字を見てから仕様を都合よく変える場合は新しいholdoutと実験IDを要求。
- 独立コードレビューがない限り、学習した方策をデフォルトにしない。

## 非目標
自律的目標設定、大型ニューラルモデル、領域間汎用知能、全自動Dream。これらは個別の後続研究で検証する。
