## 目的と立脚点

DekaSugiの知能成長を、(L0)世界の区別可能性、(L1)探索、(L2)能動的情報獲得、(L3)概念の獲得・外部化・未知世界への転移、として独立測定する。EXP-REP-004Rは役割不変性修正後の108公開質問経路で学習起因の質問切替が0、提案された11,520採点はNOT_RUN。REP005の3有料操作反例はG0の方法上の発見であり、学習成功ではない。

## 競合仮説

- OBS: H0の表現は十分で、合法的な追加質問が不足している。
- POL: 表現H0のままでも履歴に基づく問い合わせ方針で改善する。
- REP: 公開の合法的な同一状態・同一操作に相反する結果があり、決定論的無記憶H0では表現できず履歴を扱うHplusでは可能。
- INV: 与えられた解答マクロではなく汎用の型付きメタ文法から新しい実行可能な述語を観測に基づき合成できる。
- XFER: 獲得した述語をSnapshotへ保存し、構造的に未知の世界で強い固定Hplusや経験検索より有用に使える。
- SAFE: 表現範囲外、履歴2を越える依存、雑音、合法的に識別不能な環境に対し不当な確信を避ける。

## G0における測定対象

H0は可視状態と現行操作のみに依存する全決定論的関数。Hplusは公開された直前1〜2操作について、役割・型付き値の比較と論理結合とガード付き作用を持つ有限文法。学習済みHplusと固定Hplusの表現可能な意味集合と計算量上限を一致させる。既知の3ステップ反例 pulse(source) → set(source,0) → pulse(source) はH0の限界の証明だが、述語発明の証明ではない。全24役割置換と有料操作の合法性を独立検証する。

P=H0で十分、R=合法8操作以内の反例がありHplusで説明可能、U=8操作以内で合法な適応方策のどれによっても関連仮説を区別できない、N=Hplus範囲外または観測雑音。Nの決定論的範囲外と確率的雑音を混ぜて採点しない。完全な有限意味署名を役割置換に関して正規化し、別途、因果依存構造・実験操作・元生成テンプレートの共有関係から独立した意味ファミリーを定義する。単に署名が異なるだけでは独立ファミリーとしない。

既存計画のP/R/U/N各20ファミリー、TRAIN8/DEV4/EVAL8ずつ（合計80ファミリー、160世界）は、現時点で実在が証明されていない条件付き設計値。意味的な重複、役割置換、生成元の共有で数を水増ししない。実行可能性が証明できなければG0で停止し、評価前に別の事前登録を行う。統計的検出力も独立ファミリー単位で事前に評価する。

## 技術・ロジック選定

Python 3.12+標準ライブラリ、型付きASTと安全な有限インタプリタ、候補の意味等価判定、version-space、合法な反例による概念候補合成、記述長優先探索を選択する。初期はニューラル学習を導入せず、表現獲得の効果を切り分ける。後日、候補順序の学習器だけをMLPなどに置換して学習経験数・epoch・勾配更新数を別々に測定する。

Wakeは実際の有料公開操作を記録、無記憶H0の整合候補が空かを検査し、空かつHplusが成立する時だけ型付き関係候補を生成する。さらに合法的な質問で反証を試みる。Sleepは意味正規化、支持・反例・適用条件の保存を担当する。Dreamの自作データは独立した外界経験に数えない。Snapshotはハッシュとソース版を持ち、別プロセスで再読み込みする。予測は評価者の正解閲覧前にコミットする。

## 将来の評価設計（未実施）

同じ世界・開始情報・有料操作上限8・物理計算上限で、各アームは独立に適応的質問を選択する。偶然同じ質問になったアームも除外しない。H0/Hplus × 固定/文脈依存方針の2×2、能力同等のSTATIC-Hplus、学習Hplus、方針のみ学習、記憶検索のみ、BODY-OFFを比較。12の未知チャレンジ入力について正解+1、誤答-1、棄権-0.25の平均から実有料操作1件につき0.02減算する効用案。評価結果閲覧前に数値を凍結し、正答率・棄権率・計算費用・学習費償却を別途報告。世界ではなく独立した意味ファミリーを主たる統計単位にする。

G0=意味ファミリー・合法反例・同等比較・評価方法の独立レビュー、G1=公開操作と証拠来歴の隔離、G2=全有限意味の表現可能性、G3=0/8/16/32/64世界のWake→Sleep→Snapshot→未知世界使用とBODY-OFF、G4=公平な対照条件、G5=新しい公開人工工学採点、G6=効果・NULL・NEGATIVEを含む採否判断。いずれも前段階の不成立時は停止。現時点でREP005はG0方法プレチェックまでであり、学習・採点・固定モデルは存在しない。
