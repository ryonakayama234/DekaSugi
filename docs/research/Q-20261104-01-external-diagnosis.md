## 2. 監督者の診断（回答で反証・修正してよい）

- **D1 混線**: 研究は4層 — (a) 学習・表現の研究本体、(b) 測定科学、(c) 証拠保全・セキュリティ境界、(d) 統治・事前登録ゲート — が分離されないまま進み、作業量では (c)(d) が (a) を圧倒している。「学習する AI」ではなく「学習を公正に測るための金庫」を作り続けている状態ではないか。
- **D2 機会の不在**: 過去の NULL の相当部分は、学習器の失敗ではなく、実験の世界（生態系）に「学習・適応で得られる利得」自体が存在しなかった可能性を排除できていない（F4 がその極端な実例）。機会が存在しない世界での NULL は、学習器についての証拠にならない。
- **D3 帰属の未分離と先行する次実験**: 「概念本体の効果」と「方策・ランク付けの効果」の帰属が未分離のまま（#126 #136 #139）、次の実験系（REP-005、COEV-001、ACTIVE-002…）が並行して増殖した。結果として Draft PR が滞留し、main が止まった。
- **D4 プロセス観との緊張**: オーナーの知能観は「知能は静的な蓄積物ではなく動的なプロセスの中にあり、対話は相互が学べる互恵的な営み」である。一方、現行設計は知能を凍結スナップショットと封印された一回限り評価という静的な形で扱い、Wake–Sleep や能動的質問というプロセス側の仕組みも相互作用がほぼ起きない形に閉じている。この緊張は意図的な設計判断か、測定厳密化の副作用か。

## 3. 質問（各問: 結論 → 根拠（証拠へのリンク）→ 自分の結論が崩れる条件、の順で回答すること）

### QD1 — 作業量の棚卸し（D1 の検証）
2026-10-24 以降の全 PR を (a) 学習・表現の研究本体 (b) 測定 (c) 証拠保全・セキュリティ (d) 統治・事前登録・文書同期 の4分類に仕分け、件数と代表例を示せ。監督者の診断 D1 が誤りであれば、実数で反証せよ。

### QD2 — 「機会の存在」の事後監査（D2 の検証）
REP-001〜005、COEV-001、ACTIVE-001、EXP-ACTIVE-002 の各実験について、その世界に「学習・適応によって得られる利得」が設計上存在したかを、G0B と同じ厳密さで事後判定し、一覧化せよ（存在した / ゼロだった / 未判定）。あわせて、今後の全実験に「機会の存在証明を実験開始の前提条件にする」原則を置くことに同意するか。反対なら理由と代替案を示せ。

### QD3 — 帰属分離の原則（D3 の検証）
「概念本体 vs 方策・ランク付け」の帰属を分離できない実験設計は、今後開始しない（開始済みのものは帰属分離できる形に縮小するか凍結する）という原則に同意するか。具体的に、現行の HOLD 群のうち帰属分離が可能なもの・不可能なものを仕分けよ。

### QD4 — 記号的学習とパラメータ学習の非対称
オーナーの方針は「記号的学習とパラメータ学習を区別しながら進める」である。現状パラメータ学習が EXP-0002B の KNN のみであるのは、意図的な段階付けか、単なる欠落か。両層の現状・役割分担・次に埋めるべき欠落を、層別に整理して示せ。

### QD5 — プロセスとしての知能と測定の両立（D4 への回答）
Wake–Sleep や能動的質問を「凍結した成果物」ではなく「相互作用の軌跡」として評価する設計は可能か。可能な場合、証拠の厳密さ（再現性・改ざん耐性・独立評価）はどの層で担保するのか。具体的な測定対象（軌跡のどの統計量が"学んだ"ことに対応するか）を含めて提案せよ。不可能と考える場合は、オーナーの知能観と現行設計のどちらを優先すべきか、理由とともに答えよ。

### QD6 — 生態系（世界）の最低要件
GATE-R0 の中心問い（H0 が provably 不十分で、H+ が表現可能で、反例から獲得でき、強い対照を超える）に答える前に、世界の生成側が満たすべき最低要件を列挙せよ。少なくとも次の3点を含めること: (1) 機会の存在を実験前に証明できること、(2) 単一の代数的仕掛けではなく複数の独立した機構族を含むこと、(3) 情報が行動に間に合うタイミングで届くこと。要件ごとに、過去のどの実験がそれを欠いていたかを対応づけよ。

### QD7 — 監督構造について
司令塔（優先順位・停止判断）を実装担当エージェント自身が兼ねる現行構造の限界を、自己評価として述べよ。本質問票→回答→監督者精査→オーナー決定という外部監督ループを GATE-R0 の正式な入力過程として組み込むことに同意するか。同意しない場合は、代替となる独立性確保の案を示せ。

### QD8 — 滞留物の仕分け基準
open PR 約45件・open Issue 約42件について、GATE-R0 終了時点で「残す / 凍結（証拠として保持し再開しない）/ 閉じる」を判定する基準案を示せ。あわせて、main が 2026-10-30 で止まっている現状をどう評価するか（健全な停止か、統合負債か）を答えよ。
