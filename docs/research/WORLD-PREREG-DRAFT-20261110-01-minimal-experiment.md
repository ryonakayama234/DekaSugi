## 0. 主張と認定上限（凍結済みの前提）

- 主主張（認定上限 B、MR1 批准済み）: 同一 meta-runtime 上で、経験から獲得した述語・二階スキーマを用いる学習器は、同じ公開情報・同じ原始操作予算・同じ grammar 能力を持つ強い対照より、未見課題族に対する**経験効率**が高い。
- 補助主張（A）: 獲得した表現により、seed の H0 では到達できなかった合法な解法が到達可能になる場合がある（意味クラス拡張）。主判定には使わない。
- 主評価は費用（wall）ではなく転移と経験効率。実験Aの教訓として固定費支配が観測されているため、wall は主エンドポイントにしない（個別記帳はする）。
- 独立単位は「生成規則／意味 family」。行動ステップや同一世界の連続試行を独立標本として数えない。

## 1. 世界 v0（テキストエディタ、WORLD-R §2 の確定案）

- 文字: 4記号 A/B/C/D。
- 状態: buffer（初期長 4〜12、上限 16）、cursor、selection（anchor/head または none、半開区間）、clipboard。完全観測・決定的。
- 原子行動: MOVE_LEFT / MOVE_RIGHT / INSERT(symbol) / DELETE_BACK / DELETE_RIGHT / SET_ANCHOR / EXTEND_LEFT / EXTEND_RIGHT / COPY / PASTE / CLEAR_SELECTION。意味名付きマクロ（SEARCH/REPLACE 等）は与えない。
- 合法性: 端・空選択・空 clipboard・容量超過の扱いは仕様で一意に固定（no-op とし、INVALID とは数えない案を推す。凍結時に確定）。
- インターフェース: reset / observe / legal_actions / step。状態ラベルから意味カテゴリへの対応表は学習側に渡さない。
- 採点: 独立した決定的 verifier が保持する。学習側には真の target buffer・hidden rule・将来の正解列を渡さない。課題提示は匿名 task ID＋初期観測＋公開フィードバック（成功/失敗、課金対象）に限る（goal leakage 防止、WORLD-R §3）。

## 2. 課題族と封印

- 訓練族（公開）: 転写、反復コピー、観測依存編集、2段連結の4族から生成する規則 family。候補数: 24 family（校正で確定）。
- 分岐の最小証人: 共通の公開課題タグを持つ2初期状態で、正解到達に必要な行動が互いに異なる**対照ペア**を観測依存編集族に必ず含める。生成側で「同一の開ループ行動列では両方成功できない」ことと「双方に合法な別々の到達系列が存在する」ことを検査済みのペアのみを使う。
- 評価ゲート（本最小実験の範囲）:
  - G1 rename: 未見文字名への改名。target 再学習 0。
  - G2 length: TRAIN 最大長より長い独立組成。target 再学習 0。
  - G3 form（フォーム世界転移）は本実験に**含めない**（次ラウンドの事前登録で扱う。第1.5世界の仕様自体が未設計のため）。
- 封印: holdout family は生成規則単位で封印し、(述語 × 分岐先操作 × 対象) の三項組合せの分離封印とする。片方の近傍を大量に見せる split は使わない。
- 後から陽性になる課題だけを選別しない。生成した family の全件を台帳に残す。

## 3. 比較条件（arm）

全 arm で同一の公開経験・原始操作予算・問い合わせ課金・保存上限・停止条件・holdout を適用する。費用は費用ベクトルとして個別記帳し、単一の加重和に混ぜない。

| arm | 内容 | 切り分けるもの |
|---|---|---|
| FULL | 提案学習器（分節化→anti-unification→述語/技能/スキーマ候補→ANDゲート昇格） | 主張の本体 |
| OFF | FULL と同一だが、獲得した記号/スキーマの USE を無効化 | 獲得物の実利用効果（C5） |
| FIXED-IF | 同一 meta-runtime に完成済み高階 IF を seed として与えた学習器 | 「If が実行できる」恩恵と「If を発見した」効果の分離（C6） |
| LOOKUP | エピソード記憶の完全一致/近傍検索のみ | 記憶・再利用だけでの説明可能性（C2） |
| H+ | 固定 grammar の容量一致探索（総当たり上限） | 固定方策の天井（C1） |
| REC | 観測の再符号化のみ許可し、スキーマ構築を無効化した FULL | 監督者の対抗仮説「主効果は観測の再符号化」説の判別（MR7） |

- C0（開ループ固定列）と C7（evaluator-only ORACLE）は科学主張の arm とせず、§6 の機会診断でのみ使う。
- 技能昇格は AND ゲート: (i) holdout 前逐次予測の損失改善または維持、(ii) 総 MDL（library header＋body＋残差）の改善、(iii) 独立課題族への利用証拠、(iv) 原始呼出予算の非超過。すべて満たす場合のみ採用する（PW2 修正の反映）。
- 経験収集の能動探索に EIG を使う場合は proxy として扱い、最終判定は外部 holdout で行う（PW5 修正の反映）。

## 4. seed 在庫の宣言（MR3 批准済みの境界）

学習前に与えるのは meta-runtime の基盤のみとし、在庫をここに全量宣言して監査可能にする:

- 与える: decision-graph の評価、変数束縛、比較（等値・順序）の原始機能、§1 の原子行動、§3 の arm 共通インフラ（logger・verifier 接続）。
- 与えない: 述語の在庫、分岐先の対応表、スキーマ構造（SELECT_BRANCH の完成形を含む）、意味カテゴリ名、課題族の生成規則。
- 初期記号在庫は原子行動のみ。獲得された記号はすべて生成履歴と依存元を伴って台帳化される。

## 5. 測定と判定

- 経験予算 B: 公開経験（試行エピソード数×原始呼出）の上限。候補: family あたり B=200 エピソード相当（校正で確定）。学習のための初期経験も課金対象に含める。
- 主エンドポイント: holdout（G1/G2）における AULC（n=0..B の成功率の平均、WORLD-R §8 の定義）。成功/棄権/INVALID は分母に残す。
- 副エンドポイント: 予算 B 到達時点の成功率、ON/OFF の合法行動差（使用差）、最悪サブグループ（文字頻度・長さ・role swap・誤条件）の成功率。
- 判定（凍結候補、WORLD-R §8 の閾値案を継承）:
  - G1: 成功率 90% 以上、かつ最強対照に +10pp 以上。
  - G2: 成功率 80% 以上、かつ最強対照に +10pp 以上。
  - 主張 B の成立には G1・G2 双方での AULC 優位（最強対照比 +0.15 以上を候補とする）も併置する。
- 閾値は**未凍結**。凍結前に非採点の到達可能性診断（校正ラウンド）で対照の天井と難易度を確認し、安すぎる/不可能な値は校正結果に基づき一度だけ改訂してから Owner 許可で凍結する。データ確認後に閾値を動かして同じ結果を再採点しない。

## 6. 機会診断（本番前の STOP 判定、非採点）

- K0 検査: 全ての正例 family が固定 H+ または最良の合法 open-loop で解ける場合、識別機会なしとして本実験を STOP する（実験Aの二の舞を避けるための事前関門）。
- 点火診断 D0〜D3（情報不足/予算不足/学習不足/表現限界）を校正時に併走させ、表現修復の点火が D3 相当に限られることを確認する。陰性世界（H0 で完全説明可能）での誤点火率も校正項目とする。

## 7. キル条件（WORLD-R §8 の運用形）

- K0: 機会なし（§6）→ 実験自体を STOP。
- K1: FULL と OFF で合法行動・使用差なし → 獲得物の実利用を不成立とする。
- K2: 表現修復の有無を統制すると差が消失 → 帰属を再符号化側へ降格（REC arm との比較で判定）。
- K3: 最強対照との差が負または実質 0 → 主張 B 不成立。
- K4: 成績差が target 漏洩または予算差で説明できる → 当該結果を無効とする。
- （K5 は G3 を扱う次ラウンドで運用する。）

## 8. ログと再現性

- ログ契約は WORLD-R §4 の最小契約（episode_id、匿名 family id、source manifest digest、境界、agent snapshot digest、step 単位の観測・合法行動集合 digest・選択行動・delta・outcome_kind・費用ベクトル・記号提案イベント・receipt digest）をそのまま採用する。hidden rule と oracle 内部状態はログに含めない。
- 全 family・全 arm の結果（NULL/NEGATIVE を含む）を保存し、第三者監査可能な形で残す。
