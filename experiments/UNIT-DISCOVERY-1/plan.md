# UNIT-DISCOVERY-1 — 文字列から見つけた単位の再利用

設計 v1。提出コミットで方法を固定し、Muse の独立確認に付す。今回は設計文書のみ。資料の選定・取得、制作・実装、実験の実行は別の承認を要する。[第一の問い](https://github.com/ryonakayama234/DekaSugi/issues/227#issuecomment-6979105203)・[設計固定の承認](https://github.com/ryonakayama234/DekaSugi/issues/227#issuecomment-6979533498)

## Hypothesis

DekaSugi AI が日本語の文字の流れから形成した可変長の単位を参照すると、同じ文字経験から学ぶ文字予測器より、別の文書の未見文脈で次の文字に高い確率を与えられるか。後ろの文脈から手前の文字を復元する読み直しも調べる。先行の人工文法試験は未見組合せで FULL・NO-CHUNK とも6/6だった。[先行試験 #231](https://github.com/ryonakayama234/DekaSugi/issues/227#issuecomment-6950668183)

## 1. 入力と分割

- 利用条件を確認できる既存の日本語散文24文書を用いる。資料を別途承認した後、出典・利用条件・抽出手順・安定した文書ID・原文および正規化後の本文の SHA-256 を入力台帳に固定する。選定・分割の順序は結果に依存させない。
- 各原文書から本文1件を採る。改行を LF に統一し、Unicode NFC に正規化して、本文先頭の最大2,000 Unicode コードポイントを使う。文字・空白・句読点は順序どおり保持し、文書境界を越えて連結しない。利用する本文は後日台帳で確定する。ラベル、外部辞書、人手の単語境界、IME 境界は学習入力に含めない。
- 分割前に完全重複を除く。正規化・切り詰め後の文字8-gram集合の Jaccard 類似度が0.80以上の文書対を近重複とし、連結成分ごとに安定IDの UTF-8 バイト順で最初の1件だけ残す。重複除外後に固定できる文書が24件に満たなければ入力不足とする。固定した24件を、実験IDと文書IDを LF で結んだ UTF-8 バイト列の SHA-256 の昇順で並べる。同値はID順で解決する。
- 並び順の先頭12件を発見用 D、次の6件を追加学習用 L、最後の6件を評価用 E とする。**両条件の文字予測器は D の12件と L の6件を同じ順序で一巡、計18件すべてから学ぶ。** D は単位の発見にも使う。E は学習・発見・設定調整から隔離する。

## 2. 単位の発見と辞書の固定

D の各文書を一文字ずつに分けた状態から始める。各巡で隣接する現在の要素の対を数え、連結した文字列が未登録の2〜6文字で、4箇所以上・2文書以上に現れる対を候補にする。候補には、元の文字列で直前の文字と直後の文字がそれぞれ2種類以上あることも求める。文書境界は種類数に含めない。

候補から、出現箇所数の降順、左要素の展開文字列のコードポイント順、右要素の同順で先頭の1対を選ぶ。各文書を左から走査し、互いに重ならない出現を結合する。結合した要素は次巡の候補になり得る。候補が尽きるか、32個登録した時点で止める。登録順、展開文字列、結合元、支持となった文書IDと正規化後の文字位置を保存し、L・Eの処理前に辞書を固定する。正解語彙は与えず、辞書の登録件数だけでは成果判定を行わない。

## 3. 二条件の情報同等性

**条件差は、固定辞書から形成した単位の統計を予測時に参照できるかどうかだけとする。** 学習本文・順序・回数、文字モデルの状態、評価する文書・行・文字、最大24文字の可視範囲、および正解文字の表現は共通とする。文書数と総文字数に加え、学習用の順序付き文書ID・本文のハッシュと共通文字モデルのハッシュが一致することを照合する。評価行の選定は評価器が行い、文字のみ側の予測器へ辞書、単位ID、単位の境界、行の選定理由を渡さない。

- **共通の文字モデル。** 順方向と逆方向について、D∪L の全ターゲット文字の位置で、直前の最大24文字の全接尾辞を数える。方向ごとに独立して集計する。予測の出力集合 V は D∪L に現れた文字と未知文字を表す UNK。空文脈は加算1で平滑化する。文字文脈 s の確率は `P_s(y) = (C_s(y) + 8 P_suffix(s)(y)) / (N_s + 8)` とする。suffix は先頭の一文字を除いた文脈、N はその文脈の全出現数。
- **文字のみ。** 上記モデルの `P_char` をそのまま出す。複数文字列も長さ24までの文字文脈として使える。
- **単位あり。** 同じ文字モデルを使い、可視文脈の末端に一致する最長の登録単位を参照する。D∪L の同じターゲット位置に同じ最長一致を適用し、単位 u ごとに直後の文字を数える。 `P_on(y) = (C_u(y) + 8 P_char(y)) / (N_u + 8)` とする。単位が一致しないか N_u が0なら `P_on = P_char`。ユニットの統計に別の本文は使わない。
- **読み直し。** 文書と登録単位の文字順を反転し、同じ比較を行う。元の順序では、対象位置の最大24文字の右文脈を使って、登録単位の直前の伏せ字を予測する。順方向に右文脈を渡さない。どちらの方向も、モデルが見るのは可視範囲だけで、ターゲット文字を分割・照合に使わない。E の処理中に辞書や計数を更新しない。

この比較は、同じ文字経験を持つモデルに、発見した単位で文脈をまとめた統計を加える効果を測る。例として、文字モデルがある文字に0.25を割り当て、使った単位の後続2件のうち1件でその文字が出たなら、単位ありの確率は `(1 + 8 × 0.25) / (2 + 8) = 0.30`。同じ文脈で参照を無効にすると0.25に戻る。

## 4. 評価行の固定

1. 評価器は E の文書順・文字位置順に走査する。順方向の主評価は、可視文脈の末端で最長一致した単位 u と、その直前の3文字が揃い、その連結文字列が D∪L のどの文書にも連続部分列として存在しない位置の全件とする。たとえば `私はね普段｜` なら、`普段` が最長一致して `私はね普段` が未見の場合に、縦線の直後の一文字を採点する。読み直しでも向きを反転して同じ選定条件を使う。
2. 評価行は正解文字・予測値に依存する選別をせず、両条件で共通にする。単位に一致しても対応する学習計数が0の行は残し、未参照として記録する。未知の正解文字は UNK の確率で採点し、その件数を明示する。同じ位置を重複して数えない。
3. 評価器が方向・文書ID・文字位置からなる対象行を固定した後、両条件の予測を保存し、別工程で正解と照合する。各行に共通文字モデルの予測、単位ありの予測、参照の有無と単位ID・展開文字列、単位側の計数、後から照合した正解への確率を残す。元の資料や生の本文を含む証跡の共有は資料の利用条件に従う。

## Metrics

- 方向ごとに、正解への対数損失 `−log2(p)` を両条件で計算し、行ごとの差 `文字のみの損失 − 単位ありの損失` を集計する。単位は bit/文字。全対象行での平均、文書別の件数と平均、単位別の件数と平均、未参照件数を示す。順方向を主指標とし、読み直しは同じ尺度で独立に報告する。
- 壁時計時間、CPU時間、参照試行数と参照成立数を精度と別に記録する。単位発見、共通文字モデル学習、単位統計の集計、各条件の予測は分けて計時する。予測時間は同じCPU・評価順・行で比較し、両条件に共通する処理も含める。処理時間は参考測定で、精度の判定線に混ぜない。
- 初回の実装・実行が別途承認された場合の規模は1プロセス・1論理CPU、全工程の壁時計300秒までとする。上限で打ち切った回は `RESOURCE_STOP` とし、部分採点で判定しない。

## Acceptance

| 状態 | 凍結する判定 |
| --- | --- |
| 効果あり | 参照が成立した評価行が60箇所以上、4文書以上、3種以上の登録単位にまたがる。全対象行の平均改善が0.05 bit/文字以上で、参照成立行のある文書の過半でも各文書の全対象行の平均が正。改善行で単位参照と予測差が記録で照合できる。 |
| 判定保留 | 入力不足または評価の参照成立数・文書数・単位数が不足。候補が0件の場合も、発見状況を記録したうえでこの判定とする。 |
| 効果未確認 | 評価の充足条件を満たし、改善幅または文書間の条件を満たさない。悪化も記録する。 |
| 比較不成立 | 学習入力・共通モデル・評価行の不一致、参照経路の検証不合格、打切り、予測または保存の欠損がある。 |

読み直しにも同じ判定線を方向ごとに適用する。読み直しだけの改善で主判定を繰り上げない。評価後に分割・尺度・閾値を調整する場合は、別版と新しい評価資料で扱う。主張は選定された日本語散文とこの限られた比較に限定する。

## Muse の独立確認

- 設計段階では、D∪L の全18件を両条件が学ぶこと、評価器の辞書情報が文字のみ側へ渡らないこと、および同じ文字予測器から単位参照の有無だけで確率が分岐することを確認する。
- 単位内部を採点しないこと、3文字との未見照合を D∪L 全体で行うこと、方向ごとの評価行と判定線、判定保留と負の所見の扱いも照合する。
- 現段階で文書の本文・入力台帳・学習や実測の記録は作っていない。資料・制作・実行は後日の別判断とする。
