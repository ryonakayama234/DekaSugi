# EXP-ACTIVE-002 — Inquiry skill acquisition, experimental method candidate

## Hypothesis
**Primary H3+H4 candidate**: a typed conditional inquiry procedure induced from strictly paid public TRAIN observations, persisted/reloaded as an independent candidate Snapshot, and used on structurally disjoint unseen USE worlds **changes a legal question at an identical public prefix** and **improves evaluator-only unknown-transition prediction** over both same-Snapshot query-selector-OFF and strong capacity-matched STATIC active planning.

Competing: H1 opportunity absence; H2 predictor benefit without question benefit; H3 action-only switch without terminal gain; H4 renaming memorization or policy/prior-only effect; H5 original grammar inadequate, rather than inquiry failure; H6 gains canceled by TRAIN/CPU cost. Any null/negative outcome preserved.

## Design status and prior evidence
No source/seed/family split/method freeze, independent power or F0 authorization yet. Historical G0C-3 9/9 no exact MAP adaptive gain; V4 learned body dispatch can alter predictions but no selected query switch on 24 identical prefix panels; neither licenses unobserved performance claims. These are exploratory disclosed Draft results, not TRAIN or blinded FINAL for this study. ACTIVE-001 main is a different fixed 2-query world and remains unchanged.

Legal action transitions, budget and terminal utility fixed before oracle computation.
- **G1 public learner** (future distinct PR): exact finite posterior or version-space model on charged observations; record missing and inconsistent states; compare matched static inference, episodic retrieval, model-disabled and optional small neural learning curves (if separately approved).
- **G2 inquiry skill**: multiple source-independent TRAIN experiences → predeclared typed AST/MDL synthesis → hash+schema checked candidate Snapshot saved and loaded in a fresh learner process → paid USE on new legal worlds; same prefix/snapshot/belief/expressive support ON/OFF inquiry dispatch. Action switch and outcome benefit both required.
- **G3 disclosed engineering development score**: separately authorize only after exact-head safe CI and review. Evaluate matched fixed, STATIC, retrieval, ON/OFF, rank-only, and evaluator-side Oracle; include adverse worlds and costs. Evidence is explicitly engineering, not confirmatory.
- **G4 formal science / F0**: independent method/custody/power review, prospective fresh data/split/source commits and seed locks; sealed FINAL only after an additional explicit owner activation decision and reviewed evaluator. No automatic advancement.

## Population and sampling (UNFROZEN)
- Worlds: typed finite causal action model with public initial state, legal stateful operations and finite action budget; 5-bit/15-action/history2 G0C source is **reference** not automatically adopted as experiment population.
- Independent unit: source-independent *mechanism family* with an explicit ancestry rule and no shared hidden generating template that would cause pseudo-replication. State renamings/seed variants/repeated audit probes within family must remain clustered.
- Two **separate** evaluation tracks: deliberately built positive/negative opportunity fixture calibration, and a prior-frozen non-outcome-filtered population including NULL, INVALID, NOT_CERTIFIED, no-early-branch, unidentifiable, negative-transfer and no-useful-adaptation. Condition on opportunity only as secondary analysis with declared denominator.
- Candidate action budgets B={1,2,3,4}, learning exposures {4,8,16,32,64}, optional neural epoch {0,1,4,16}; engineering suggestions, not powered frozen sizes. Source-only feasibility may stop or revise version before any new study freeze. Runtime cap/proof timeouts cannot count as zero difference.
- No reused EXP-0002B FINAL112, EXP-0003A DEV64/FINAL128, OPPORTUNITY original private data, G0C-3 posthoc closed panels or other old scored data as new confirmatory holdout.

## Arms and fairness
| Arm | Snapshot/inference | Inquiry selector | Role |
|---|---|---|---|
| FIXED | common published grammar | best preregistered open-loop schedule | nonadaptive |
| STATIC | same representable grammar and public budget | strong fixed-source adaptive lookahead | hardest nonlearning |
| RETRIEVAL | public TRAIN episode retrieval | preregistered nearest-case policy | memorization control |
| LEARNED-OFF | SAME frozen learned model/priors/posterior/grammar as ON | learned inquiry-skill dispatch disabled ONLY at selector | primary ablation |
| LEARNED-ON | SAME model/belief/snapshot as OFF | learned inquiry-skill dispatch enabled | treatment |
| RANK-ONLY / BODY-OFF | separately matched learned rank / body feature | fixed selector where applicable | mechanism localization |
| ORACLE | evaluator-only private truth/prior | exact optimal policy in certified closed class | ceiling, not deployed learner |

No model inference leakage from source family, true `Law`, evaluator-only probe labels, future outcomes, hidden seeds or prior paired-arm scores. Each arm restarts an independent physical episode with same world/initial state. Initial public prefix is shared; after question divergence each arm receives its own lawful observed outcomes and pays each intervention. No simulated unexecuted outcome is charged as a real public observation. Fairness includes both paid action count and CPU/candidate cap; report if any static algorithm is stronger or uses a different expressive hypothesis space.

## Metrics
- Define each world with evaluator-selected legal probe/prediction trajectories not supplied to learner; fixed count and prediction utility before any learner-scored use.
- `U=(correct-wrong)/N_probe`, with abstention=0 is **PROPOSED**. Coverage, error rate, exact prediction score and calibration where probability predictions exist are reported separately. No sampling of probes conditional on a successful policy.
- Primary estimator candidate: equal predeclared-weight family mean of within-family/world paired `U(LEARNED-ON)-U(LEARNED-OFF)`. Secondary: `ON-STATIC`, query-switch frequency on identical prefix, best open-loop vs adaptive certified headroom, transfer over disjoint motifs, negative transfer, log-loss/Brier if probabilistic.
- Positive mechanism gate: legal changed action attributable to learned-skill selector, actual paid public answer, positive heldout utility; no inference from mere output entropy or renamed motif; don't claim representative improvement from a constructed-positive subset.
- Cost report: paid TRAIN and USE steps, `C_total(M)=C_train+M*C_use` for several prospective `M`, number of model evaluations, interpreter calls, CPU/wall per stage, memory if measured. Report net differences vs static including precomputation.
- Preliminary practical effect threshold +0.05 utility and 95% family-cluster CI lower >0; sample size, alpha family, power>=80%, CI method, multi-arm corrections, cluster construction and effect distribution **NOT_FROZEN**. An independent method reviewer must approve these before a new source/seed/method freeze; no numerical threshold is a current authority.
- States: `NOT_RUN`, `INVALID`, `NOT_CERTIFIED`, `UNDERIDENTIFIED`, `MODEL_INCONSISTENT`, `UNIDENTIFIABLE`, `ABSTAIN`, `NEGATIVE`; report denominator and reasons explicitly.
